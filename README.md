# KotoMogu｜食语兽

KotoMogu 是一款使用 Unity 开发的互动虚拟宠物原型。使用者可以通过语言和手势与小龙交流，小龙会根据输入内容、饱食度、心情和体力做出相应反应，也会在空闲时自主活动。

本项目以「语言成为食物，交流产生陪伴」为核心概念，探索语音识别、手势识别与虚拟角色行为的结合。

## 已实现功能

- **语音交互**：通过麦克风自动收音，由本地语音识别服务转换为文字，支持中文、日语和英语。
- **指令识别**：根据关键词触发问候、跳跃、进食、开心、睡眠和唤醒等行为。
- **手势交互**：通过摄像头识别张开手掌、握拳和竖起拇指，并触发对应动作。
- **自主行为**：根据角色状态进行空闲活动、低体力睡眠和饥饿表现。
- **角色动画**：包含呼吸、问候、跳跃、进食、开心、睡眠、左右张望、拍翅、点头、鞠躬，以及饥饿和虚弱表现。
- **状态管理**：维护饱食度、心情、体力和进食次数，并支持本地保存。
- **调试界面**：提供文字输入、动作测试和状态查看功能，可在正常体验时隐藏。

## 交互示例

| 输入方式 | 内容 | 角色反应 |
|---|---|---|
| 语言 | 你好／こんにちは／Hello | 问候 |
| 语言 | 跳一下／ジャンプして／Jump | 跳跃 |
| 语言 | 可爱／かわいい／Cute | 开心 |
| 语言 | 晚安／おやすみ／Sleep | 睡眠 |
| 语言 | 起床／起きて／Wake | 唤醒 |
| 手势 | 张开手掌 | 问候 |
| 手势 | 握拳 | 进食 |
| 手势 | 竖起拇指 | 开心 |

动作是否执行还会受到当前状态、体力、饱食度和冷却时间的限制。

## 技术构成

- **Unity / C#**：场景、角色控制、动画播放、状态管理与输入接收。
- **Python / faster-whisper**：本地语音识别。
- **Python / MediaPipe / OpenCV**：摄像头采集与手势识别。
- **HTTP**：Unity 与语音服务之间的通信。
- **UDP**：手势服务向 Unity 发送识别结果。

当前语言理解采用关键词规则，并非自由对话型语言模型。

## 运行方式

1. 使用兼容版本的 Unity 打开项目，等待资源导入和脚本编译完成。
2. 首次使用时，安装语音服务与手势服务所需的 Python 依赖，并下载识别模型。
3. 启动语音服务 `VoiceServer/02_start.bat`。
4. 启动手势服务 `GestureServer/02_start.bat`。
5. 在 Unity 中打开项目场景，点击 **Play**。
6. 确认麦克风和摄像头可用，再进行语言或手势交互。

默认语音服务地址为 `http://127.0.0.1:8765`，手势接收端口为 `8766`。两个服务均在本机运行。

## 当前限制与后续计划

项目目前处于原型阶段。语音和手势识别速度受电脑性能、环境噪声、光线及摄像头条件影响，仍需优化响应速度和稳定性。

角色动作主要通过模型部件动画实现。后续计划完善动画过渡、自主行为优先级、日常互动反馈和部署流程，让小龙的表现更加自然。

当前的饥饿与虚弱属于状态反馈，尚未实现完整的死亡与复活系统。
